# 一，GPIO简介
- GPIO (General Purpose Input Output）通用输入输出口。
- 四种输入模式，四种输出模式。
- 引脚电平：低电平0V~3.3V，FT可以容忍5V。
- 输出模式：通过端口控制高低电平。**作用**：驱动LED，控制蜂鸣器，模拟通信协议输出时序(如I2C，SPI等芯片特定的协议)等**任何可用高低电平控制的地方**。
- 输入模式：可读取端口电平或电压。**作用**：**读取按键输入**，外接模块电平信号输入，ADC电压采集，模拟通信协议接收数据等)

- GPIO外设名称按照GPIOA，GPIOB，GPIOC等命名
- GPIO共16个引脚，编号从0到15
- 每个GPIO中主要包含寄存器和驱动器
- **寄存器**：一段特殊的储存器（内核可通过APB2总线对寄存器读写），寄存器每一位对应一个引脚，输出寄存器写1时为输出高电平，0时为输出低电平
- 驱动器：增大驱动能力

**输入部分**
- **保护二极管**：当输入的电压高于3.3V，上方的保护二极管会接通，电流流入V<sub>DD</sub>，当输入电压低于0V时，下方的保护二极管会接通，电流会从引脚流出，以此来保护内部电路
- **开关**：输入驱动器中上方开关连接上拉电阻，下方开关连接下拉电阻。**作用**：避免引脚悬空而导致输入数据不稳定

| 上开关 | 下开关 |   模式   |       功能       |
| :-: | :-: | :----: | :------------: |
| 导通  | 断开  | 上拉输入模式 | 悬空时，输入提供默认的高电平 |
| 断开  | 导通  | 下拉输入模式 | 悬空时，输入提供默认的低电平 |
| 断开  | 断开  | 浮空输入模式 |                |
- **施密特触发器**（肖特基触发器为翻译错误）：对输入电压进行整形（执行逻辑：当输入电压高于某一阈值时，输出瞬间升为高电平；当输入电压低于某一阈值时，输出电压瞬间降为低电平) **作用**：避免因信号抖动而造成输出抖动
- **模拟输入**：连接ADC（模数转换器），接收数字量，故在施密特触发器前。
- **复用功能输入**：连接在其他需读取端口的外设上，故在施密特触发器后。
___
**输出部分**
- 数字部分可由**输出数据寄存器**或**片外外设**（**复用功能输出**）控制
- 梯形：数据选择器
- **输出数据寄存器**：某一位就可以操作对应端口，只能同时配置
- **位设置/清除寄存器**：可单独操作输出数据寄存器的某一位，而不影响其他位。e.g：当要对某一位置1处理时，在未设置寄存器对应位写1，其他写0即可，对应位置1，其他位不变；需清0时，在位清除寄存器对应位写1，其他位写0即可，对应位清0，其他位不变。(库函数)
- **P/N-MOS**：与三种输出模式有关，分别为**推挽输出模式**，**开漏输出模式**，**关闭模式**。
- **推挽输出模式**（**强推输出模式**）：P-MOS和N-MOS均有效，信号又输出数据寄存器控制。当其为1时，P-MOS导通，N-MOS断开，输出接入V<sub>DD</sub>，输出高电平；当其为0时，P-MOS断开，N-MOS导通，输出接入V<sub>SS</sub>，输出低电平。该模式STM32对I/O有绝对控制权。
- **开漏输出模式**：P-MOS无效，N-MOS工作，数据寄存器为1时：N-MOS断开，为高阻模式；为0时，N-MOS导通，输出接入V<sub>SS</sub>，输出低电平。该模式只有低电平有驱动能力，高电平无驱动能力。**作用**：可作为通信协议的驱动方式（I2C通信）；可避免在多机通讯时，各个设备的相互干扰；用于输出5V的电平信号（在外部接一个上拉电阻到5V的电源，当输出高电平时，由外部上拉电阻拉至5V）
- **关闭模式**：当引脚配置为输入模式时，两个MOS管均无效，端口电平由外部信号控制

# GPIO的八种模式
**通过配置端口配置寄存器，可将端口配置成下面8种模式**

|  模式名称  |  性质  |            特征             |
| :----: | :--: | :-----------------------: |
|  浮空输入  | 数字输入 |   可读取引脚电平，若引脚悬空，则电平不确定    |
|  上拉输入  | 数字输入 | 可读取引脚电平，内部连接上拉电阻，悬空时默认高电平 |
|  下拉输入  | 数字输入 | 可读取引脚电平，内部连接下拉电阻，悬空时默认低电平 |
|  模拟输入  | 模拟输入 |    GPIO无效，引脚直接接入内部ADC     |
|  开漏输出  | 数字输出 |  可输出引脚电平，高电平为高阻态，低电平接VSS  |
|  推挽输出  | 数字输出 |  可输出引脚电平，高电平接VDD，低电平接VSS  |
| 复用开漏输出 | 数字输出 |  由片上外设控制，高电平为高阻态，低电平接VSS  |
| 复用推挽输出 | 数字输出 |  由片上外设控制，高电平接VDD，低电平接VSS  |
- 除了**模拟输入模式**，数字输入是无效的，其他模式中，数字输入均有效
