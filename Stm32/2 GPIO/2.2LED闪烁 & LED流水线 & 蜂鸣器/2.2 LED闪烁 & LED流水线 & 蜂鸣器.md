# 一，LED和蜂鸣器结构介绍
1.**LED**：发光二极管，正向通电导通，反向通电不亮
	长脚为正极，短脚为负极；内部小的为正极，大的为负极
2.**有源蜂鸣器**：内部自带振荡源，将正负极接上直流电压即可持续发声，频率固定。内部电路如下
![](Pasted%20image%2020260912223016.png)
- VCC和GND分别接正负极 ，中间接低电平就会响，高电平关闭
3.**无源蜂鸣器**：内部不带振荡源，需要控制器提供振荡脉冲才可发声，调整提供振荡脉冲的频率，可发出不同频率的声音

# 二，LED和蜂鸣器的电路接法
## 1.LED的电路接法
1.1该接法低电平导通，高电平熄灭
![](Pasted%20image%2020260912224106.png)
1.2该接法高电平导通，电平熄灭
![](Pasted%20image%2020260912224112.png)
**注意**：大多数单片机都是**高电平弱驱动，低电平强驱动**（**作用**：防止两个引脚，一个强行拉高、一个强行拉低，直接对灌短路，烧坏 IO），故一般电路设计选择第一种

## 2.蜂鸣器电路接法
- 对于功率较大的设备，直接用IO口驱动对STM32的负担太重，故这里使用三极管驱动电路
- **三极管**：左边为基极，带箭头的是发射极，剩下的就是集电极。无论对于PNP型还是NPN型，都是**带箭头的电位高于箭头指向的点位**才导通

2.1 **PNP**型三极管驱动电路：低电平接通，高电平断开
![](Pasted%20image%2020260912224631.png)

2.2  **NPN**型三极管驱动电路：高电平接通，
![](Pasted%20image%2020260912224638.png)

- PNP型三极管最好接在上边，NPN型三极管最好接在下边。
	原因：三极管的通断需要在发射极和基极之间产生一定的开启电压，如果把负载接在集电极，则可能导致三极管打不开。

# 三，GPIO代码
## 1.使用STM操作GPIO步骤
- 使用**RCC**开启GPIO的时钟
- 使用**GPIO_Init**函数初始化GPIO
- 使用**输出或输入函数**控制GPIO口
	共涉及RCC和GPIO两个外设
## 2.常用RCC函数
**RCC AHB外设时钟控制**：
`void RCC_AHBPeriphClockCmd(uint32_t RCC_AHBPeriph, FunctionalState NewState);`

**RCC APB2外设时钟控制**：
`void RCC_APB2PeriphClockCmd(uint32_t RCC_APB2Periph, FunctionalState NewState);`

**RCC APB1外设时钟控制**：
`void RCC_APB1PeriphClockCmd(uint32_t RCC_APB1Periph, FunctionalState NewState);`
 - 使能或失能AHB时钟
## 3.常用GPIO函数
`void GPIO_DeInit(GPIO_TypeDef* GPIOx);`
- 复位所指定GPIO外设

`void GPIO_AFIODeInit(void);`
- 复位所指定的AFIO外设

**`void GPIO_Init(GPIO_TypeDef* GPIOx, GPIO_InitTypeDef* GPIO_InitStruct);`**
- 用结构体的方式来初始化GPIO口
- **一般初始化外设都使用这个函数**

`void GPIO_StructInit(GPIO_InitTypeDef* GPIO_InitStruct);`
- 把结构体变量赋一个默认值

```
uint8_t GPIO_ReadInputDataBit(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin);
uint16_t GPIO_ReadInputData(GPIO_TypeDef* GPIOx);
uint8_t GPIO_ReadOutputDataBit(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin);
uint16_t GPIO_ReadOutputData(GPIO_TypeDef* GPIOx);
```
- GPIO读取函数

```
void GPIO_SetBits(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin);
//把指定端口设置为高电平
void GPIO_ResetBits(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin);
//把指定端口设置为低电平
void GPIO_WriteBit(GPIO_TypeDef* GPIOx, uint16_t GPIO_Pin, BitAction BitVal);
//根据BitVal的值设定指定端口的电平，Bit_SET为高电平；Bit_RESET为低电平
void GPIO_Write(GPIO_TypeDef* GPIOx, uint16_t PortVal);
//同时对16个端口进行写入，uint16_t PortVal直接用16进制表示
```
- GPIO写入函数
主要的是GPIO初始函数和8个读写函数

# 四，LED闪烁代码
```
#include "stm32f10x.h"                  // Device header
#include "Delay.h"

int main(void)
{
//  使用RCC开启GPIO的时钟
		RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
//  使用GPIO_Init函数初始化GPIO
	//	该代码是定义结构体的形参，名字为GPIO_Instructure
		GPIO_InitTypeDef GPIO_Instructure;
	//	推挽输出模式
		GPIO_Instructure.GPIO_Mode = GPIO_Mode_Out_PP;
	//	引脚0
		GPIO_Instructure.GPIO_Pin = GPIO_Pin_0;
	//	输出速度为50MHz	
		GPIO_Instructure.GPIO_Speed = GPIO_Speed_50MHz;
	//	GPIO的0号引脚就被设置为了推挽输出模式，50MHz的速度了
		GPIO_Init(GPIOA, &GPIO_Instructure);
		
	while(1)
	{	
//	使用输出或输入函数控制GPIO口
		GPIO_SetBits(GPIOA,GPIO_Pin_0);
		Delay_ms(500);
		GPIO_ResetBits(GPIOA,GPIO_Pin_0);
		Delay_ms(500);
		GPIO_WriteBit(GPIOA,GPIO_Pin_0,(BitAction)0);
		Delay_ms(500);
		GPIO_WriteBit(GPIOA,GPIO_Pin_0,(BitAction)1);
		Delay_ms(500);
	}
}

```

# 五，LED流水线代码
```
#include "stm32f10x.h"                  // Device header
#include "Delay.h"

int main(void)
{
		RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

		GPIO_InitTypeDef GPIO_Instructure;
		GPIO_Instructure.GPIO_Mode = GPIO_Mode_Out_PP;
		GPIO_Instructure.GPIO_Pin = GPIO_Pin_All;
		GPIO_Instructure.GPIO_Speed = GPIO_Speed_50MHz;
		GPIO_Init(GPIOA, &GPIO_Instructure);

		
	
	while(1)
	{	
	//  ~为取反符;0x0001 16进制表示PA1
		GPIO_Write(GPIOA , ~0x0001); //0000 0000 0000 0001
		Delay_ms (500);
		GPIO_Write(GPIOA , ~0x0002); //0000 0000 0000 0010
		Delay_ms (500);
		GPIO_Write(GPIOA , ~0x0004); //0000 0000 0000 0100
		Delay_ms (500);
		GPIO_Write(GPIOA , ~0x0008); //0000 0000 0000 1000
		Delay_ms (500);
		GPIO_Write(GPIOA , ~0x0010); //0000 0000 0001 0000
		Delay_ms (500);
		GPIO_Write(GPIOA , ~0x0020); //0000 0000 0010 0000
		Delay_ms (500);
		GPIO_Write(GPIOA , ~0x0040); //0000 0000 0100 0000
		Delay_ms (500);
		GPIO_Write(GPIOA , ~0x0080); //0000 0000 1000 0000
		Delay_ms (500);
	}
	
}

```

```
#include "Delay.h"

int main(void)
{
		RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);

		GPIO_InitTypeDef GPIO_Instructure;
		GPIO_Instructure.GPIO_Mode = GPIO_Mode_Out_PP;
		GPIO_Instructure.GPIO_Pin = GPIO_Pin_12;
		GPIO_Instructure.GPIO_Speed = GPIO_Speed_50MHz;
		GPIO_Init(GPIOB, &GPIO_Instructure);

		
	
	while(1)
	{	
		GPIO_ResetBits(GPIOB, GPIO_Pin_12);
	}
	
}

```
