# 二，建立工程
1.1必要文件 
Start中包含[固件库]中：
	1.启动文件
	2.stm32外设寄存器描述文件：寄存器种类及地址
	3.时钟配置文件
	4.内核寄存器描述文件

1.2 **添加头文件路径**
工程选项 -> c/c++ -> include Path -> 添加Start

1.3 **导入库函数**
需在工程文件夹新建Library，User文件夹存放[固件库]中的库函数
- conf（confguration）文件：配置库函数头文件函数包含关系 
- it（itterrupt）文件：存放中断函数 
 然后在工程中建立同名文件夹，将工程文件文件夹内的文件添加到工程分组
 Include Paths中添加\Start，\User和\Library（所有包含头文件的文件夹）

1.4.**宏定义**
在头文件中找到条件编译语句
~~~
USE_STDPERIPH_DRIVER
~~~
将其复制到工程项目中c/c++选项中的Dfine

1.5 **建立main函数**
新建User文件->右键添加新文件main.c
- 文件最后一行必须为空行

1.6 **配置调试器**
工程选项->Debug->Use 选择手头的适配器 ->Setting ->Flash Download 勾选Reset and Run

## 四， 基于库函数开发工程 
~~~
#include "stm32f10x.h"                  // Device header

int main(void)
{
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC,ENABLE);
	GPIO_InitTypeDef GPIO_InitStructure;
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_13;
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init (GPIOC, &GPIO_InitStructure);
//	GPIO_SetBits(GPIOC,GPIO_Pin_13);
	GPIO_ResetBits (GPIOC,GPIO_Pin_13);
	 while(1)
	{
		
	}
}

~~~
- 右键库函数 ->Go To Definition Of ’库函数‘ -> 可以查看该库函数的介绍以及使用方法
